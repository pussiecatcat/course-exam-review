# 互动自测

互动自测在**完整资料交付之后**，由用户主动说“开始自测”才开启。不要在生成讲义的过程中打断用户做题。

## 一、准备

读取：

```
course-review/self-test/bank.json
.review/self_test_log.json        # 不存在就新建 []
```

`bank.json` 每题字段：

```json
{
  "id": "Q1",
  "topic": "Path loss exponent",
  "section": "2.3",
  "source": "【往年题｜2024 秋 Q2】",
  "question_en": "...",
  "answer_en": "...",
  "analysis_zh": "...",
  "pitfall": "...",
  "type": "calculation"
}
```

如果 `bank.json` 不存在，退回读 `self-test/questions.md` + `answers.md`，但要在开始前告诉用户“题库文件缺失，用 Markdown 版本”。

## 二、出题节奏

1. 先问用户：从哪一章/哪个知识点开始？默认从 Q1 顺序。
2. 一次只出一题，英文题干。计算题给必要参数和单位。
3. **用户回答前不显示答案、解析、提示**。若用户说“不会”，先给一个方向性提示（不含最终答案），仍不会再讲解。
4. 用户回答后：
   - 先判断对错/部分对；
   - 给中文解析（为什么、条件、步骤、易错点）；
   - 给英文参考答案；
   - 告诉用户这题对应讲义哪一节、原始材料哪一页。
5. 记录到 `.review/self_test_log.json`。
6. 每 5–10 题做一次小结：正确率、薄弱知识点、建议回看章节。
7. 用户说“停”/“结束”时给总报告，并建议如何调整复习计划。

## 三、评分

| 类型 | 看什么 |
|---|---|
| 概念 `concept` | 关键词是否到位；是否混淆相近概念；能否举反例 |
| 计算 `calculation` | 公式选择、单位、代入、中间量、最终数量级 |
| 推导 `derivation` | 起点、假设、每步依据、结论 |
| 对比 `comparison` | 是否说清“相同点/不同点/适用场景” |
| 应用 `application` | 是否把条件映射到模型；是否检查结果合理性 |

- 计算题：最终答案对但单位/条件错，判“部分对”；答案错但方法对，给方法分并指出错在哪一步。
- 用户用中文回答：接受；关键英文术语可以在反馈里补上。
- 用户只给最终数字：追问“怎么来的”，再判分。

## 四、错题记录

`.review/self_test_log.json` 是数组，每次追加：

```json
{
  "time": "2026-10-29T20:15:00",
  "question_id": "Q1",
  "topic": "Path loss exponent",
  "section": "2.3",
  "type": "calculation",
  "user_answer": "...",
  "correct": false,
  "partial": true,
  "weak_point": "把 40 dB 直接当成 gamma；忘记 d0=1 m",
  "source": "【往年题｜2024 秋 Q2】"
}
```

- `correct`：完全正确；`partial`：部分正确。
- `weak_point` 用一句话写“错在哪个概念/步骤”，不要只写“粗心”。
- 同一知识点连续错 2 次，标记为“高风险”，在总结里优先回看。

## 五、薄弱点回链

小结时输出：

```markdown
### 本轮小结（Q1–Q8）
- 正确 5 / 部分对 2 / 错 1
- 高风险：路径损耗指数拟合（§2.3）——连续 2 题单位/斜率出错
- 建议回看：course-review/index.html#h-16（§2.3）；PPT p.8–9；笔记 §2.3
- 建议练习：Q3、Q7 重做；速查表“距离翻倍/翻十倍”一行
```

回链优先级：

1. 讲义对应小节（HTML 锚点/PDF 页码）；
2. 原始课件页；
3. 作业/往年题原题；
4. 速查表对应行。

## 六、调整复习计划

根据错题：

- 某 A 级知识点正确率 < 60%：在计划中加 0.5–1 小时 + 2 道变式题；
- 连续两次错同一概念：回到讲义该节，重读“条件/易错点”，再做 1 题；
- 计算错误集中在单位/数量级：只练速查表的“单位/翻倍”清单，不重读整章；
- 概念混淆：做一张 A vs B 对比表，放进速查。

不要因为一次错题重写整份讲义；只做局部补强。

## 七、边界

- 不泄露答案：用户回答前不显示 `answer_en` / `analysis_zh`。
- 不替用户做题：用户说“直接告诉我答案”时，可以先给提示；坚持要答案再给，并标注“这样练习效果会打折”。
- 不把自测题冒充往年题：反馈里保留 `source` 原文。
- 不跨课程复用题库：每门课单独 `bank.json`。
- 不把用户答案上传到外部服务。
