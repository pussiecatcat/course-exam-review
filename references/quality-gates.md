# 质检门槛

`check.py` 检查可机检项；其余在交付前按本文件自检。任何一项不通过，先修内容，不降低门槛。

## 一、覆盖（硬门槛）

- 非 skip 内容页覆盖率 **100%**。
- `coverage.csv` 的 `section` 列不得为空；`skip` 必须有 `status` 理由。
- 只允许封面、目录、致谢、纯章节分隔页 `skip`；**内容页不允许 skip**。
- 读不懂/看不清的页标 `to-verify`，仍要出现在 coverage 和 `TO_VERIFY.md` 中。
- 未覆盖页 > 0：`coverage.py --strict` 返回非零，`check.py` 判失败。

## 二、来源与事实（硬门槛）

- 每章末尾有 `来源`，至少包含课件文件名 + 页码。
- 每个独立公式所在小节能追到来源页/笔记页。
- 每个例题有来源：`【作业｜文件名 题X】`、`【往年题｜年份 题X】` 或 `【课件｜文件名 p.X】`。
- 每张图有中文图注，图注含来源页。
- 补充内容有 `【补充】`；外部资料有 `【外部｜...】`；自编题有 `【自测·生成】`。
- 不确定内容有 `【待核】`，并进 `TO_VERIFY.md`。
- 不出现课件中没有的人名、年份、标准号、公式编号；外部结论必须标来源。

## 三、公式（硬门槛）

- `$` 成对；`$$` 成对；无孤立定界符。
- 行内公式不跨行；独立公式单独成段。
- 同一符号全篇一致；符号表覆盖正文出现的所有符号。
- 单位正体；多字母下标用 `\mathrm{}`。
- PDF 文本层中不出现 `$...$`、`\frac`、`\mathrm` 等原始 LaTeX。
- 渲染后无红色报错、无 `Undefined control sequence`。
- 不同材料符号不同：有对照/换算表；冲突列出出处。

## 四、结构（硬门槛）

必须存在的章节：

1. 导读（范围、假设、用法、符号约定）；
2. 知识地图（章节关系、前置、学习顺序、优先级依据）；
3. 各章精讲（按知识体系，不按 PPT 页码）；
4. 速查（概念/公式/易混/易错）；
5. 英文自测题（只有题目）；
6. 答案（中文解析 + 英文答案）；
7. 复习计划；
8. 覆盖与待核对。

章内要求：

- 章开头有“本章解决什么问题 / 前置知识 / 与前后章联系 / 优先级依据”。
- 每个 A 级知识点覆盖：定义/直觉、条件、公式/单位、推导、联系、易错、例题。
- 范围外内容有 `out-of-scope` 标记。
- 标题层级不跳级；表格有表头；图有 alt 文本。

## 五、自测（硬门槛）

- Q/A 数量相等，编号一一对应。
- 题目文件只有题目，不含答案；答案文件只有答案/解析，不重复整套题（可引用题干一句话）。
- 题干英文；解析中文；参考答案英文。
- 每题有来源；自编题标 `【自测·生成】`，不冒充往年题。
- 答案含：题型识别、方法/条件、步骤、检查；不能只有最终数字。
- A 级知识点至少 1 题；2–3 讲 15–30 题，整门课 40–80 题。
- `bank.json` 字段完整，可被互动自测读取。

## 六、计划（硬门槛）

- 有考试日期：按天排，任务不超过 `daily_hours`。
- 无日期：默认 7 天，并在开头写“假设”。
- 无每日时长：不排具体日期，只给任务顺序 + 预计耗时，写明假设。
- 预留约 20% 给自测/错题回顾。
- 范围外内容单列，不占主计划。
- 时间不足有保底方案（A 级 + 速查 + 错题）。
- 不虚构用户时间；假设逐条列出。

## 七、覆盖报告（硬门槛）

- `94-coverage.md` 含：总览、逐来源表、跳过页、缺失页、待核对。
- 覆盖率数字与 `coverage.csv` 一致。
- `TO_VERIFY.md` 每条有：ID、位置、问题、处理建议。
- 没有“已完整覆盖”的空话；覆盖率不足要明说。

## 八、PDF / 网页

- 中文无乱码；公式渲染正常；图片清晰、未被裁切。
- 分页：标题不孤行、表格不截断、公式不超页宽。
- 目录锚点全部可达；交叉引用（§、p.、Q/A）指向存在。
- HTML 离线打开正常；KaTeX 本地；无外部 CDN 依赖。
- PDF 页数 > 0；A4；文本层可提取；空白页不超过 20%。
- 自测 questions.pdf 不含答案；answers.pdf 含解析。

## 九、源文件包

- `source/content/` 含全部 Markdown。
- `source/figures/` 含讲义引用的全部图片。
- `source/meta.json`、`exam_profile.json`、`knowledge_points.csv`、`outline.md`、`coverage.csv`、`TO_VERIFY.md` 存在。
- `source/scripts/`、`templates/report.html`、`assets/` 存在。
- `source/README.md` 有编译命令。
- 从 `source/` 重新编译能生成 PDF，页数与交付版一致或差异有说明。

## 十、内容质量自检

逐章问：

1. 这三句话结论，能不能直接背？
2. 公式的每个符号，符号表里有没有？
3. 推导的每一步，假设有没有写？
4. 例题换一个数字，读者能不能照着做？
5. 易错点是不是“错误做法 → 为什么错 → 正确做法”？
6. 图注有没有说清坐标轴、曲线、参数？
7. 这一节和前后章的联系，能不能用一句话说清？
8. 优先级依据是 `[明确]` 还是 `[推断]`？有没有把推断写成“必考”？
9. 读不懂的地方，有没有诚实标 `【待核】`？

任何一题答“否”，回去改，不交付。

## 十一、常见返工原因

| 现象 | 根因 | 修法 |
|---|---|---|
| 讲义像目录 | 只抽标题，没看图 | 逐页看图，补公式与例题 |
| 公式对不上课件 | 擅自换符号/近似 | 统一课程记号，补符号表 |
| 例题只有答案 | 没写“为什么” | 按五段式重写 |
| 易错点空泛 | 没结合题目 | 每条绑定一个具体错误 |
| PDF 公式乱码 | KaTeX 资源缺失 | 确认 `assets/katex/fonts` 完整 |
| 自测题答案泄露 | 题目文件混入答案 | 拆成 91/92 两个文件 |
| 计划像课程表 | 没有按优先级/依赖排 | 用 `plan.py`，检查 A/B/C 与前置 |
| 覆盖率 95% 就交 | 把内容页标了 skip | 内容页必须归节；读不懂标 to-verify |
| 范围外内容占太多 | 没区分 in/out | 标 out-of-scope，计划不排 |
| 源文件不能编译 | 图片仍指向 `slides/` | 用 `package.py` 复制并改写路径 |
