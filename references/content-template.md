# 讲义内容模板

每一章一个 Markdown 文件，放在 `.review/content/`。文件名按顺序：`00-guide.md`、`01-knowledge-map.md`、`02-*.md`……`90-quick-reference.md`、`91-self-test.md`、`92-self-test-answers.md`、`93-review-plan.md`、`94-coverage.md`。

## 文件头

```markdown
---
title: 第 2 讲 路径损耗与阴影衰落
short: 路径损耗
slides: 1-11
weight: ★★★
priority: A
scope: in
map: true
keypoints: 平均+起伏 · K 与 γ · 对数正态 · 中断概率
---
```

| 字段 | 含义 |
|---|---|
| `title` | 讲义一级标题 |
| `short` | 侧栏与考试地图用短名，≤ 6 字 |
| `slides` | 覆盖的 PPT 页码，可写 `1-11, 15` |
| `weight` | 复习优先级星标 `★★★/★★/★`，给读者看 |
| `priority` | `A/B/C/D`，给计划和质检用；`D` 表示范围外 |
| `scope` | `in` / `out`；范围外标 `out` |
| `map` | 是否进“考试地图”，导读/自测/计划/覆盖写 `false` |
| `keypoints` | 考试地图“核心考点”列，3–6 个短词 |

## 章开头：先给地图

每章不要一上来就堆公式。开头按下面顺序：

```markdown

::: lead
一句话说清这一章解决什么问题、最后得到什么工具。
:::

## 2.1 本章在课程中的位置

### 前置知识

::: prereq
**需要先会**：自由空间路径增益 $P_r/P_t=G_l(\lambda/4\pi d)^2$；dB 与线性功率的换算。
**在本章的作用**：$d_0$ 处的 $K$ 就是用它算出来的；后面所有 dB 表达式都建立在“乘法变加法”上。
:::

### 与前后章的联系

::: connect
**上一章**：……  
**下一章**：……  
**本章在整个链路预算中的位置**：……  
:::

### 考试优先级

::: exam
**优先级 A**｜**依据**：[明确] 老师强调 Example 2.3/2.4；[推断] 课件连续 3 页出现、作业同型题。  
**在考试范围内**：是。  
**可能题型**：拟合 $\gamma$、估 $\sigma$、算 $P_{\mathrm{out}}$。
:::
```

- `prereq` 块只补当前章真正用到的前置，不写成教材章节。
- `connect` 块要具体：哪条公式、哪个物理量、哪一章会用到。
- `exam` 块必须区分 `[明确]` 和 `[推断]`；不要把推断写成“必考”。

## 知识点九段

每个知识点用 `##` 开头，按需取用以下九段。不要为了凑格式写空段。

```markdown
## 2.3 简化路径损耗模型

### 核心定义与物理意义

一句话定义；再用“如果……会怎样”的对比解释物理图像。

### 成立条件与适用范围

- 远场：$d\gg h_t,h_r$；
- 单径/平均意义：只给平均趋势，不预测某一点；
- $d_0$ 必须与拟合时一致。

### 公式、变量与单位

| 符号 | 含义 | 单位 | 备注 |
|---|---|---|---|
| $K$ | 参考距离处的路径增益 | 线性 | $K=P_r(d_0)/P_t$ |
| $K_{\mathrm{dB}}$ | $K$ 的 dB 值 | dB | 通常为负 |
| $\gamma$ | 路径损耗指数 | 无量纲 | 自由空间 2，二径 4 |

$$
P_r^{\mathrm{dBm}}=P_t^{\mathrm{dBm}}+K_{\mathrm{dB}}-10\gamma\log_{10}\!\left(\frac{d}{d_0}\right)
$$

逐项说明每个量管什么、什么时候可以删掉。

### 推导与依据

**Step 1｜起点**：……  
**Step 2｜代入**：……  
**Step 3｜取 dB**：……

> 【补充】课件没展开、为理解补上的步骤；考试按老师给的版本写。

### 与其他知识点的联系

- 与自由空间/二径模型：$\gamma=2/4$ 是本模型的特例；
- 与阴影衰落：本模型给均值，阴影给起伏；
- 与中断概率：均值进入链路余量 $\Delta$。

### 易混点与易错点

::: warn
**错误做法**：把距离翻倍当成 +20 dB。  
**为什么错**：翻倍只增加 $10\gamma\log_{10}2\approx3\gamma$ dB。  
**正确做法**：翻 10 倍才是 $10\gamma$ dB。
:::

### 典型例题

**例 2.3（PPT p.8–9｜作业 HW2 题3｜往年题 2024 秋 Q2）**

按五段写：题目在问什么 → 为什么这么做 → 每步算术 → 结果检查 → 套路。

### 来源

【课件｜2-Path Loss(2).pptx p.8–9】；【作业｜HW2 题3】；【补充】。
```

## 公式与推导

- 行内 `$...$`，独立 `$$...$$`。
- 多字母下标用 `\mathrm{}`：`$P_{\mathrm{rx}}$`。
- 单位用 `\,\mathrm{dBm}`，正体。
- 同一符号全篇一致；课程用 $\alpha$ 就不要换成 $\gamma$，在符号表注明“老师也写作 $\gamma$”。
- 推导每一步只做一件事，写清“因为/所以/代入”；近似写条件（远场、小角度、$x\ll1$）。
- 课件省略的推导标 `【补充】`，并说明“考试是否要求”。
- **表格单元格里不要出现未转义的 `|`**；需要绝对值或条件竖线时用 `\lvert ... \rvert` 或 `\mid`。

```markdown
- **Topic:** Path loss exponent
- **Section:** 2.3
- **Type:** calculation
- **Source:** 【往年题｜2024 秋 Q2】

**Question (English):**  
A 900 MHz indoor link uses the simplified path-loss model with $d_0=1$ m and $K=-31.54$ dB. Measurements give $M(10\,\mathrm{m})=-70$ dB and $M(100\,\mathrm{m})=-110$ dB. Estimate the path-loss exponent $\gamma$ and explain the assumption behind your estimate.
```

### 答案文件 `92-self-test-answers.md`

```markdown
## A1 · Path loss exponent

**中文思路：** 先认题型——两点拟合 $\gamma$；再确认 $d_0=1$ m，所以 $\log_{10}(d/d_0)=\log_{10}d$；用斜率公式。

**English answer:**  
Using the simplified model in dB, the slope is $10\gamma$ dB/decade. From 10 m to 100 m the measured loss increases by 40 dB over one decade, so $10\gamma=40$ and $\gamma=4$. This assumes the measurements follow the simplified model and that shadowing is averaged out.

**易错点：** 把 40 dB 直接当成 $\gamma$；忘记 $d_0=1$ m 时 $\log_{10}(d/d_0)=\log_{10}d$。

**回到讲义：** §2.3、§2.6。
```

要求：

- 题号 `Q1...` 与答案 `A1...` 一一对应。
- 题干英文；解析中文；参考答案英文。
- 自编题标 `【自测·生成】`；往年题标 `【往年题｜年份 题X】`；作业题标 `【作业｜文件名 题X】`。
