# 考试画像与优先级

每门课单独建一份 `.review/exam_profile.json`。**不能沿用上一门课的考试设置**：即使都是电子系专业课，开闭卷、题型、范围、老师强调都可能完全不同。

## 一、先收集什么

按可靠性排序：

1. **用户明确说的**：考试日期、剩余天数、每天可用时长、范围、题型、开闭卷、老师强调。
2. **材料里写的**：考试大纲、复习提纲、作业说明、往年题卷面、课件中的“Exam”“考点”“Homeworks”标注。
3. **从材料推断的**：重复出现的公式、例题、作业同型题、课件页数占比。
4. **外部资料**：教材章节、课程官网、往年题答案；只在需要时用，标来源。

不要为了填满 JSON 而编造。缺失项写 `null` 或用默认值，并在讲义“导读”和计划里说明假设。

## 二、字段

```json
{
  "course": "无线通信",
  "exam_date": "2026-11-05",
  "today": "2026-10-28",
  "daily_hours": 3,
  "exam_type": "closed-book",
  "question_types": ["选择", "计算", "简答"],
  "scope": "第 2–4 讲；第 5 讲不考",
  "emphasized": ["路径损耗拟合", "中断概率"],
  "materials": {
    "homework": ["HW2", "HW3"],
    "past_exams": ["2024 秋期中"]
  },
  "notes": "老师明确说 Example 2.3/2.4 会考",
  "assumptions": ["每日 3 小时由用户提供", "开闭卷未说明时按闭卷准备"]
}
```

| 字段 | 怎么用 | 缺失时 |
|---|---|---|
| `exam_date` | 算剩余天数、排计划 | 默认今天 + 7 天，写明假设 |
| `today` | 计划起点 | 用系统日期 |
| `daily_hours` | 每天任务上限 | 不排日期，只给任务顺序 + 预计耗时 |
| `exam_type` | 提示答题方式；不据此删内容 | 不改变内容，计划里注明“未说明” |
| `question_types` | 自测题型配比、例题呈现 | 按课件信号推断，标 `[推断]` |
| `scope` | in-scope / out-of-scope | 全部提供的课件都算 in-scope |
| `emphasized` | 提高优先级 | 不用；按信号排序 |
| `materials.homework` | 例题/自测优先来源 | 用课件例题 |
| `materials.past_exams` | 题型/重点/难度 | 用课件信号 |
| `notes` | 老师原话、特殊要求 | 空 |

## 三、优先级规则

| 级别 | 判定依据 | 计划处理 |
|---|---|---|
| **A** | 考试范围明确列出；老师明确强调；往年题直接命中；作业核心题；本章主公式/主推导 | 必排，先排；配例题 + 自测 |
| **B** | 课件跨页重复；有例题；核心公式的变形；作业同型题 | 排入主计划，时间不足时可压缩 |
| **C** | 背景、应用、历史、扩展阅读；课件只出现一次且无公式 | 速查/一句话带过，不单独排 |
| **D** | 超出已知考试范围 | 仍写进讲义，标 `out-of-scope`，计划不排 |

### 明确 vs 推断

每条优先级都要写依据标签：

- `[明确]`：考试范围/老师原话/往年题/作业要求直接支持。
- `[推断]`：根据课件信号、重复、例题、页数占比推断。

例：

```markdown
**优先级 A**｜**依据**：[明确] 老师强调 Example 2.3/2.4；[推断] 作业 HW2 有同型题，课件连续 3 页出现。
```

只有 `[明确]` 才能写“必考”。`[推断]` 写“重点/高频/建议掌握”。

### 范围外

- 课件里有、但考试范围明确排除：写进讲义，标 `out-of-scope`，在 coverage 里仍算“已覆盖”。
- 课件里没有、但往年题考过：单独列“范围外但考过”，提醒用户确认；不要直接塞进主线。
- 范围不明确：默认全部 in-scope，在导读里说明“范围未提供，按全部课件复习”。

## 四、作业与往年题

1. 先做**题型分布表**：题型 × 分值 × 覆盖章节（能从卷面读出来的）。
2. 把每道题映射到知识点 ID（`KPxx`），命中即提高该知识点优先级。
3. 原题放进对应知识点的“典型例题”，标 `【往年题｜年份 题X】` 或 `【作业｜文件名 题X】`。
4. 答案与课件冲突：列出两处出处和差异，不静默选一个；在 `TO_VERIFY.md` 记录。
5. 往年题超出当前课件范围：单独列，不混进主线；计划里标“需确认是否在本次范围”。

## 五、开闭卷与题型

- **开卷**：重点放在“快速定位 + 公式条件 + 题型识别”；速查表要更全，例题要标“在资料哪一页”。
- **闭卷**：重点放在“必背结论 + 推导骨架 + 易错点”；速查表压缩到 1–2 页。
- **选择题**：多写概念辨析、易混点、单位/符号陷阱。
- **计算题**：多写例题变式、自测计算、结果检查。
- **简答/论述**：多写“定义—条件—对比—例子”的答题模板。
- **证明/推导**：多写每一步依据、适用条件、反例。

开闭卷/题型未说明时，**不要据此删内容**；在计划里注明“按常规准备”，自测覆盖多种题型。

## 六、冲突处理

材料之间符号/答案不一致时：

1. 保留各自原符号，做一张“符号对照/换算”表；
2. 在正文写“材料 A 用 $\alpha$，材料 B 用 $\gamma$，二者关系是……”；
3. 答案冲突：列出两处出处、数值差异、可能原因（四舍五入/参考距离不同/符号约定不同）；
4. 不静默选择；无法判断时标 `【待核】`。

## 七、写进讲义的位置

- `00-guide.md`：考试画像摘要、范围、假设、优先级图例。
- `01-knowledge-map.md`：每章优先级 + 依据 + 前置关系。
- 各章开头 `::: exam`：本节优先级 + 依据 + 可能题型。
- `93-review-plan.md`：计划假设、A/B/C/D 分配、范围外单列。
- `94-coverage.md`：覆盖 + 待核对。
